# Afalight

> Shenzhen Afalight Co., Ltd. (深圳市埃尔法光电科技有限公司) is a Chinese optoelectronics
> manufacturer founded in 2016. It designs and builds photoelectric modules, optical engines
> and active optical cable assemblies — HDMI, USB-C, DVI and LC fiber optical modules and
> fiber-optic extenders — for ultra-high-definition and 8K video transport, split TVs,
> projectors, VR hardware, industrial and medical imaging, and automotive electronics.

Afalight is a hardware supplier, not a software or API company. As of 2026-09-12 it publishes
no developer portal, no public API, no SDK, no webhook surface and no machine-readable API
contract (no OpenAPI, AsyncAPI, GraphQL SDL, MCP server or A2A agent card). This file is
generated by API Evangelist from the public company profile; it is not published by Afalight.

## Products

- HDFiberLink — HDMI over fiber optical modules and extenders.
- HEXWaveLink — USB-C / DVI photoelectric hybrid modules, including USB-C to HDMI switching with KVM.
- FSO AxisLink — free-space optical and axis-link transmission modules.
- LC single-fiber and dual-fiber optical modules; fiber extenders carrying IR and RS-232 control.
